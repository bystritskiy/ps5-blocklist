# PlayStation blocklist

265 доменов PlayStation для блокировки через Pi-hole или AdGuard Home.

Добавьте [Raw-ссылку на список](https://raw.githubusercontent.com/bystritskiy/ps5-blocklist/main/playstation-domains.txt) в списки блокировки и обновите Gravity. Применяйте список только к консоли.

Список блокирует точные домены, затрагивает обновления, PSN, трофеи и загрузки игр. Не гарантирует блокировку всех обновлений; на консоли не проверен.
